공부길 개발 계획서

중·고등학생이 수업 내용과 오답을 정리하고, 시험과 수행평가를 준비하고, 공부 시간을 관리하는 학습 플랫폼을 실제 서비스로 만들기 위한 계획입니다.

대상중1 ~ 고3 학생
함께 쓰는 사람학부모 · 선생님
개발 기간(가정)18주
출시 형태웹 + PWA

01개요와 목표

공부 내용을 기록하고, 약한 부분을 찾아 반복하고, 시험까지 남은 시간을 계획으로 바꿔 주는 학생 중심 서비스입니다.

해결할 문제수업 메모, 오답, 시험 일정, 공부 시간이 노트·사진·앱에 흩어져 있어 복습 시점을 놓친다.
핵심 가치기록은 쉽게, 분석은 자동으로, 다음 할 일은 구체적으로. 학부모·선생님은 같은 데이터를 열람하며 응원한다.
하지 않는 것정답 대신 풀어 주기, 수행평가 대필, 학생 간 순위 경쟁. 학습 습관과 이해를 돕는 데 집중한다.

02현재 상태

10개 기능 화면이 있는 웹 프로토타입이 완성되어 있습니다. 데이터는 브라우저 저장소에만 있고 AI 분석은 Claude 연결 화면에서만 켜집니다.

구분프로토타입실서비스에서 바뀌는 것
데이터 저장브라우저 localStorage, 예시 데이터서버 DB, 계정별 저장, 기기 간 동기화
사용자화면 전환으로 학생·학부모 모드 시뮬레이션실제 계정, 초대·연결, 권한 분리
사진축소본을 브라우저에 저장객체 스토리지에 원본 저장, 접근 제어
AI화면에서 직접 호출서버에서 호출, 사용량·비용 관리, 결과 저장
알림없음복습 시점, 마감, 시험 D-day 푸시 알림

화면 구성, 용어, 계산 규칙(D-day 로드맵, 복습 주기, 달성률)은 프로토타입을 기준 명세로 재사용합니다.

우선순위는 출시에 꼭 필요한지(필수), 출시 직후 가치가 큰지(중요), 이후에 해도 되는지(후순위)로 나눴습니다.

혼공 타이머필수없음서버 시각 기준 기록, 앱을 닫아도 유지, 일일 목표, 연속일
대시보드필수없음공부 시간, 점수 추이, 과목별 현황, 코멘트

04사용자와 권한

역할할 수 있는 일볼 수 없는 것
학생모든 기록 작성·수정·삭제, AI 분석 요청, 보호자·선생님 초대다른 학생 데이터
학부모연결된 자녀의 대시보드·계획·오답 열람, 코멘트 작성학생이 비공개로 둔 메모
선생님연결된 학생의 수업 노트 작성, 과목 범위 열람, 코멘트 작성자기 과목 외 상세 기록(학생 설정에 따름)
  • 연결은 학생이 만든 초대 코드로 시작하고, 학생이 언제든 해제할 수 있습니다.
  • 열람 범위는 항목별 스위치(점수, 오답 사진, 메모)로 학생이 조절합니다.
  • 한 명의 학부모·선생님이 여러 학생을 볼 수 있어야 하므로 연결 테이블로 모델링합니다.

05시스템 구조

웹앱 한 개가 화면과 API를 함께 제공하고, 무거운 AI 작업은 비동기 작업으로 분리합니다.

클라이언트

HTTPS · 인증 쿠키
애플리케이션

서버 간 호출
데이터·AI
PostgreSQL계정, 기록, 권한객체 스토리지오답·시험지 사진Claude API이미지 포함 분석, JSON 출력
타이머는 시작 시각을 서버에 저장하고 경과 시간은 항상 서버 시각으로 계산합니다. 탭을 닫거나 기기를 바꿔도 기록이 어긋나지 않게 하기 위해서입니다.

06기술 스택

영역선택이유
프레임워크Next.js(App Router) + TypeScript화면과 API를 한 코드베이스로 관리, 프로토타입 로직 재사용
스타일CSS 변수 토큰 + Tailwind프로토타입의 라이트·다크 토큰을 그대로 이식
데이터베이스PostgreSQL (Supabase 또는 Neon) + Drizzle관계형 데이터가 많고 행 단위 접근 제어가 필요
인증이메일 + 카카오·구글 로그인학생 접근성, 보호자 초대 흐름
파일S3 호환 스토리지, 서명 URL사진은 비공개로 저장하고 짧은 유효시간 URL로만 노출
AIClaude API (서버 호출)이미지 입력과 구조화된 JSON 응답, 키는 서버에만 보관
배포·운영Vercel, Sentry, PostHog빠른 배포, 오류 추적, 사용 지표

위 선택은 제안입니다. 팀의 숙련도에 따라 바꿔도 구조에는 영향이 없습니다.

08AI 기능 설계

AI는 서버에서만 호출하고, 응답은 정해진 JSON 형식으로 받아 검증한 뒤 저장합니다. 모든 AI 기능은 실패해도 기본 기능이 동작해야 합니다.

기능입력출력목표 지연실패 시 대체
오답 분석문제 사진 1장, 과목·단원·메모핵심 개념, 틀린 이유, 바로잡기, 연습 문제, 팁15초직접 입력 저장 유지, 재시도
수업 정리수업 메모 텍스트제목, 핵심 정리, 숙제, 질문5초줄 단위 규칙 정리
암기 전략시험지 사진 최대 3장, 범위 텍스트단원별 핵심, 암기법, 방법 설명20초범위 줄 단위 기본 전략
모의 테스트과목, 범위, 학년4지선다 문항과 해설20초내장 문제 은행
자동 계획시험일, 점수, 대기 오답날짜별 할 일 목록8초규칙 기반 배치
수행평가 단계제목, 유형, 마감일단계와 기한5초유형별 기본 단계
과목 진단점수, 시간, 오답 요약5줄 텍스트15초과목별 안내 콘텐츠

품질을 지키는 장치

  • 응답은 스키마로 검증하고, 형식이 틀리면 한 번만 재요청한 뒤 대체 경로로 넘어갑니다.
  • 수학·과학 풀이에는 “AI 분석은 참고용”을 표시하고, 학생이 잘못된 분석을 신고하는 버튼을 둡니다.
  • 과목별 평가 문항 세트를 만들어 출시 전과 프롬프트 변경 때마다 정확도를 확인합니다.
  • 학생별 일일 호출 상한, 같은 입력 캐시, 이미지 해상도 제한으로 비용을 관리합니다.
  • 수행평가는 단계 계획과 점검 질문만 돕고 완성된 글이나 발표 대본은 대신 써 주지 않습니다.

09개인정보·안전

사용자 대부분이 미성년자이므로 설계 단계부터 개인정보 보호를 기본값으로 둡니다.

  • 만 14세 미만 가입자는 법정대리인 동의 절차가 필요할 수 있습니다. 중학교 저학년이 대상에 포함되므로 Phase 0에서 법률 검토를 받고 가입 흐름에 반영합니다.
  • 수집 항목은 서비스에 필요한 최소한으로 하고, 사진은 비공개 스토리지에 저장하며 짧은 유효시간의 URL로만 보여 줍니다.
  • 전송과 저장 모두 암호화하고, 학부모·선생님의 열람 기록을 남깁니다.
  • AI 제공자로 전송되는 데이터의 범위를 가입 시 고지하고, 입력 데이터가 모델 학습에 쓰이지 않는지 계약·설정을 확인합니다.
  • 사진 업로드 화면에 이름·학번이 보이면 가리도록 안내하고, 이미지 메타데이터는 제거합니다.
  • 학교 시험지는 본인 학습 용도로만 쓰고 다른 사용자와 공유하거나 문제 은행에 재사용하지 않습니다.
  • 탈퇴하면 계정과 사진을 정해진 기간 안에 삭제합니다.
법령과 해석은 바뀔 수 있으므로 출시 전에 전문가 확인이 필요합니다. 이 문서는 법률 자문이 아닙니다.

12품질과 테스트

  • 단위 테스트: D-day와 주 경계 계산, 달성률, 연속 공부일, 복습 일정 날짜.
  • 권한 테스트: 학생 간 데이터 격리, 연결 해제 후 접근 차단, 항목별 열람 범위.
  • E2E 테스트: 가입, 계획 추가와 체크, 타이머 기록, 오답 업로드와 분석, 학부모 초대 열람.
  • AI 평가: 과목별 평가 문항으로 정확도와 형식 오류율을 측정하고, 프롬프트를 바꿀 때마다 다시 실행합니다.
  • 접근성·반응형: 키보드 조작, 명도 대비 AA, 360px 폭, 라이트·다크 테마.
  • 성능·보안: 첫 화면 표시 시간 목표 설정, 파일 업로드 검증, 일반적인 웹 취약점 점검.
